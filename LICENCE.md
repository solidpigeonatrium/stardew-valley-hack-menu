## 🧩 About

**Stardew Valley overlay** is a curated list of Stardew Valley open-source tools:

- **Overlays** — on-screen helpers, layout notes, hitbox viewer, startpos switcher
- **Quality-of-Life Helpers** — icon catalog, skin manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Practice Helpers
- Startpos Switcher — practice from any checkpoint
- Show Hitboxes — visualize obstacle hitboxes
- Replay Notes — record and review level runs
- Playback Speed — adjust editor playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Icon Catalog — browse icons, colors, trails, death effects
- Custom Skin Notes — organize player cosmetics
- Solid Wave Trail — improved wave visibility

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any layout
- Gravity Flip Control — manually switch gravity mid-level
- Jump Buffer Notes — chain complex maneuvers in the editor

## 🛠️ Troubleshooting

- **Overlay does not appear:** Ensure the game is running in windowed or borderless mode. Try running the helper as administrator.
- **Hotkey conflicts:** Change `menu_hotkey` in the config file to a key not used by the game.
- **Game crashes on launch:** Verify game version matches the helper's supported version. Disable other mods temporarily.
- **Antivirus alert:** Some tools may be flagged due to overlay launch. Add the folder to exclusions if you trust the source.
